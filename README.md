# Psychomatica

The minimal single-page website for [psychomatica.com](https://psychomatica.com).

## Run locally

This is a dependency-free static site. From the project directory, run:

```sh
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Files

- `index.html` — the centered wordmark
- `styles.css` — the full-screen layout
